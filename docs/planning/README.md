The current software catalog has six services/14 kW. Historical nine-service requirements and the separate hospital equipment drill-down must not be silently mixed. Hardware acceptance is still pending; B5 is explicitly deferred. The [demo guide](../DEMO_GUIDE.md) documents what is currently visible and measured.

The primary planning route is `/grid` (separate synthetic 6 kW district); `/demo` is the 31-appliance controller, `/city` its legacy illustration, and `/console` its persisted history. The [Round 3 plan](ROUND3_JUDGE_RESPONSE_PLAN.md) tracks the integrated profile and remaining acceptance gates.
